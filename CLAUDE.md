# «Опора» — инструкции для Claude

Перед любой работой прочитай **HANDOFF.md** целиком (там всё о проекте, решения, процесс выпуска), затем README.md.

## Как работать с Дмитрием
- Дмитрий — психолог, не программист. Отвечай по-русски, просто, без кода и терминов. Кратко: что сделано, где посмотреть, один следующий шаг.
- Делай всё сам: код, проверка в браузере, коммит и пуш, обновление демо. Скриншоты результата показывай.
- Отстаивай своё мнение, если Дмитрий не прав, — объясни почему. Последнее слово за ним.
- Пароли, платежи, публикация в магазинах — только вместе с ним.

## Выпуск изменений (кратко, подробно — HANDOFF.md, раздел 4)
1. Проверка: `python3 -m http.server 8767` из корня, телефон 390×844, светлая и тёмная тема; `python3 tools/sweep.py` → должно быть `90 routes []`.
2. Повысить `VERSION` в `sw.js`, новые js-файлы — в список FILES в `sw.js` и в `index.html`.
3. Коммит и `git push origin main` (сайт: GitHub Pages из main).
4. Демо: `python3 tools/build_demo.py` → `../opora.html`, опубликовать в тот же артефакт (ссылка в HANDOFF.md).
5. В конце работы — обновить HANDOFF.md.

Папка `отзывы/` — записи тестировщиков, только на компьютере, в git не попадает.
