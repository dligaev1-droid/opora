## 3. Устройство кода

- Чистый JS без сборки, один `index.html`, все модули в `js/` подключаются по порядку (порядок важен — см. index.html). Модули оборачивают друг друга: `VIEWS[route]=[view,bind]`, поздний модуль подменяет ранний (например, `retain.js` переделывает главную, `simple.js` — для новичков).
- Навигация: `go(route, sub)`, `render()`; `window.render` оборачивают retain.js, ui.js, haptic.js, simple.js. `TAB_OF[route]` — какая вкладка нижнего меню активна.
- Данные: всё в `localStorage` ключ `opora_v1`, глобальный объект `S`, сохранение `save()`. Ничего не уходит на сервер.
- Важные поля `S`: `moods, days, tests, thoughts, grat, relief, cardLog, xp/xpDay/seed` (дерево), `badges`, `sleep`, `goals` (цели: list, hab, focus, fmin, energy, rd — чтение: books/log/min/goal, fown — своё время фокуса), `love` (раздел пары, `plus`/`all` — доступ), `intim` (18+, `adult`), `onb` (знакомство), `simple` (постепенное открытие для новичков), `tours`/`tipsSeen` (экскурсии и подсказки), `theme`, `vib`, `calm` (антистресс), `snd` (звуки).
- Дни: в «Целях» `dayNum()` (UTC-полночь по местной дате), в остальном строки `dayKey()` `YYYY-MM-DD`.
- `sw.js` — офлайн-кэш. **При каждом выпуске повышать `VERSION`** (сейчас `opora-v58`), новые js-файлы добавлять в список FILES.
- Подробный список файлов — в README.md. Новые за последние дни: `theme.js` (ночная тема по времени 21–7), `achieve.js` (56 достижений), `howto.js` (свёрнутые «Как выполнять»), `calm.js` (10 антистресс-игр), `simple.js` (новичкам: спокойная главная + экскурсии), `haptic.js` (вибрация), `cardfx.js` (анимация карт МАК).

## 6. Ключевые решения и почему

- **Тесты только официальные и бесплатные:** GAD-7 (тревога), PHQ-9 (подписан «Депрессия»), WHO-5 (благополучие; ≤50 → предложение PHQ-9), Розенберг (самооценка), CBI (выгорание). Под каждым мелким шрифтом источник. Бека, Бернса, HADS, EPDS, ECR-RS — нельзя (лицензии). Несерьёзные упражнения честно подписаны «не научный тест».
- **Дневник мыслей** — по КПТ (Бек), искажения популяризировал Бёрнс; формулировки свои.
- **Новичкам — постепенно** (после отзывов Алёны и Ивана: «непонятно, что это и куда нажимать»): первый экран о пользе; `simple.js` — день 1: «Как вы?», «Шаг на сегодня», SOS; день 2 — карта дня, дерево, мысль дня; день 3 — всё. Экскурсии с подсветкой в «Я», «Мы», «Цели», «Близости» — один раз. Касается только тех, кто начал после 28.10.2026.
- **Антистресс — 10 режимов, больше не добавлять** (человеку в тревоге трудно выбирать). Очки +10 один раз за сессию после оценки «до/после».
- **Карты МАК:** сначала показываются неувиденные; при повторе — свёрнутые прошлые ответы для сравнения; в течение дня тройка карт не меняется.
- **Вибрация** только на Android (iPhone не даёт сайтам). Переключатель в «Психолог» → «Оформление».
- **Ночная тема** по умолчанию по времени 21:00–7:00; можно «как в телефоне»/светлая/тёмная.
- **Прокачка:** дерево 33 уровня / 11 стадий; тропа 11 уровней; сад 11 уровней; 56 достижений. Не ускорять.
