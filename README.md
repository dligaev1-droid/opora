# Опора — приложение психолога Дмитрия

**Адрес:** https://dligaev1-droid.github.io/opora/

Веб-приложение (PWA): открывается по ссылке, ставится на телефон как обычное приложение и работает без интернета. Без регистрации и рекламы, все записи хранятся только на устройстве пользователя.

## Что внутри

| Раздел | Что делает |
|---|---|
| Главная | Отметка настроения, быстрая помощь, ярлыки к разделам, подсказка «установить на телефон» |
| SOS | Дыхание «квадрат», заземление 5-4-3-2-1, шаги при панической атаке, телефоны помощи (нажимаются) |
| Близость 18+ («Опора+ Всё») | Знак 18+ и подтверждение возраста, только просвещение без откровенных материалов, без диагнозов и назначений. Бесплатно: первая статья, тест (без советов), «Согласие и границы», «Помощь». Код тарифа: `allCodes` в `js/config.js` |
| Режим «Цели без выгорания» (Опора+) | Переключатель «Я / Мы / Цели». Меню: Сегодня · Цели · Привычки · Фокус · Путь, зелёная тема. Бесплатно: 1 цель, 2 привычки, фокус, энергия, 1 разбор, день 1 программы |
| Режим «Для пары» (Опора+) | Переключатель «Я / Мы» в шапке. Своё нижнее меню: Сегодня · Вместе · Свидания · Путь · Психолог, своя тёплая тема. Бесплатно: день 1 программ, тест на стиль привязанности, первый уровень вопросов, один разбор ссоры, одна статья. Остальное по подписке (пока открывается кодом из `js/config.js` → `plusCodes`). Для пары: «Погода в паре» с графиком и отчётом месяца, тест «Совпадаем ли мы», вечера для двоих, скрипты трудных разговоров. Скидка подписчикам на консультации — `plusDiscount` в `js/config.js` |
| Звуки для сна | Дождь, море, лес, костёр, поющая чаша, мягкий шум; смешиваются, таймер выключения |
| Тесты | GAD-7 (тревога), PHQ-9 (депрессия), WHO-5 (благополучие) с комментарием психолога и историей результатов |
| Дневник | Настроение, теги, «что было хорошего», график за 14 дней, закономерности по тегам |
| Мысли | Дневник мыслей КПТ в 6 шагов с оценкой эмоции до и после |
| Психолог | О психологе, заявка на консультацию, список «что обсудить на сессии», удаление данных |

## Как поменять текст о себе

Откройте `js/config.js` и замените значения в кавычках. После любых изменений файлов увеличьте номер версии в первой строке `sw.js` (`opora-v1` → `opora-v2`), чтобы у пользователей подтянулась новая версия.

## Как открыть в VS Code и запустить

1. VS Code → File → Open Folder → выберите папку `opora`.
2. Слева откройте «Расширения» (Ctrl+Shift+X), найдите **Live Server** (автор Ritwick Dey) и нажмите Install. Это нужно один раз.
3. Откройте `index.html` и нажмите **Go Live** в нижней строке. Приложение откроется в браузере и будет само обновляться при каждом сохранении файла.
4. Чтобы смотреть как на телефоне: в браузере F12 → значок телефона (Ctrl+Shift+M).

## Как выложить в интернет (бесплатно)

Это статический сайт без сервера и сборки, его можно разместить на любом хостинге:

- **GitHub Pages**: загрузить файлы в репозиторий → Settings → Pages → Deploy from branch → `main`, папка `/ (root)`.
- **Netlify**: перетащить папку проекта на app.netlify.com/drop.
- Свой домен (например, opora-psy.ru) подключается в настройках любого из них.

Для установки на телефон и офлайн-режима сайт должен открываться по **https** — оба варианта дают его автоматически.

## Важно

- Приложение не ставит диагнозы и не заменяет консультацию.
- Персональные данные никуда не отправляются. Если позже добавим аккаунты, оплату или серверную часть, понадобится политика обработки персональных данных и согласие пользователя (152-ФЗ), а данные граждан РФ нужно хранить на серверах в России.

## Перед запуском платной подписки

1. В `js/config.js` заполните `legalName` (ФИО полностью) и `inn` (если самозанятый) — они подставятся в политику конфиденциальности и согласие.
2. Уведомите Роскомнадзор об обработке персональных данных (записи клиентов приходят вам в Telegram).
3. Подготовьте оферту: цена, срок, продление только с явного согласия (закон с 1 марта 2026), реквизиты продавца.
4. Для платной версии лучше перенести хостинг на российский сервер (сейчас GitHub Pages, США).
5. Покажите тексты юристу, раздел «Близость 18+» — ещё и врачу. В первую очередь статьи «Контрацепция», «Инфекции, передающиеся половым путём», «Боль — не норма», «Гормоны простыми словами» и курс «Близость после родов» (файлы `js/intim.js`, `js/intim2.js`).

## Тесты: что научное, а что нет

В приложении только научные тесты, которые авторы разрешили использовать свободно, в том числе в платном продукте.

| Тест | Разрешение |
| --- | --- |
| GAD‑7, PHQ‑9 | Pfizer: без ограничений авторского права и бесплатно |
| Шкала самооценки Розенберга | Мэрилендский университет: бесплатно и без уведомления, с научной ссылкой |
| CBI, шкала личного выгорания | NFA (Дания): свободно для некоммерческих и коммерческих целей с обязательной ссылкой на источник — ссылка стоит под тестом |
| WHO‑5, индекс благополучия ВОЗ | Psychiatric Research Unit (CORC): бесплатно, разрешение не нужно; балл ≤50 — предложение пройти PHQ‑9 |

Убраны: ECR‑RS и CSI‑4 — авторы не публикуют условий свободного использования.
Игры и упражнения (стиль привязанности, «языки любви», «Совпадаем ли мы», «Тормоза и газ», «Карта близости», колесо баланса) — авторские, подписаны как «не научный тест».
